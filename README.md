# The Most Boring Object, Reviewed in One Line

## Entry text (171 characters, one line, no trailing newline)

> There are eleven teaspoons in this drawer. Nine are missing. This one has stirred 3,000 cups of tea and never left the house. It has perfect attendance. Its name is Colin.

## How to run

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
Standard library only — no dependencies to install.

## Short audit

The review works in three beats:

1. **The count that does not add up** — eleven teaspoons in the drawer,
   nine missing, so only two are actually there. The drawer is already
   losing before the review starts.
2. **The heroic non-event** — this one teaspoon has stirred 3,000 cups of
   tea and never left the house. A lifetime of service, zero travel,
   zero drama: the most boring possible career, stated as a record.
3. **The twist at the end** — after all that dutiful nothing, it has
   perfect attendance, and then the punchline lands: its name is Colin.
   A teaspoon with a name, a record, and nowhere to go.
